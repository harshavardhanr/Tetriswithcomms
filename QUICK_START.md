# Quick Start Guide - Room Code System

## Super Simple Connection (30 seconds!)

Both devices just need to enter the **same room code**. That's it!

### Step 1: Choose a Room Code
Pick any simple code you'll remember:
- `1234`
- `game1`
- `tetris`
- `myroom`

**Requirements:**
- At least 3 characters
- Letters and numbers work
- Case doesn't matter (GAME1 = game1)

### Step 2: On VR Headset

1. Open browser and go to:
   ```
   https://harshavardhanr.github.io/Tetriswithcomms/index.html
   ```

2. Enter your room code (e.g., `1234`)

3. Click "Join Room"

4. Click "Start AR Session" when ready

5. **Wait for controller to connect**

### Step 3: On Your Phone

1. Open browser and go to:
   ```
   https://harshavardhanr.github.io/Tetriswithcomms/phone.html
   ```

2. Enter the **same room code** as VR (e.g., `1234`)

3. Click "Join Room"

4. When connected, control buttons will appear!

### Step 4: Play!

Use the phone buttons to control:
- **⬅️ Left** - Move piece left
- **➡️ Right** - Move piece right
- **⬇️ Down** - Move down faster
- **🔄 Rotate** - Rotate piece
- **⚡ Drop** - Instant drop

## Troubleshooting

### "VR headset not found in this room"
- Make sure VR headset joined the room **first**
- Check you entered the **exact same room code**
- Room codes are case-insensitive but must match exactly

### "Room code already in use"
- Someone else is using that code
- Choose a different code
- Or refresh both pages to start fresh

### Connection Dropped
- Just click "Join Room" again with the same code
- Both devices should reconnect automatically

## Tips

✅ **DO:**
- Use simple codes like `1234` or `game`
- Make sure VR joins first, then phone
- Use the same WiFi network (not required, but faster)

❌ **DON'T:**
- Use spaces in room codes
- Use codes shorter than 3 characters
- Use special characters like @#$%
