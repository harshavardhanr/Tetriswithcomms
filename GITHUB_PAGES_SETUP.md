# GitHub Pages Setup - Easiest Way!

## Your Repository
`harshavardhanr/Tetriswithcomms`

## Setup Steps

### Option 1: Deploy from Main Branch (Recommended)

1. **Merge this branch to main:**
   - Go to: https://github.com/harshavardhanr/Tetriswithcomms
   - Click "Pull requests" → "New pull request"
   - Or just merge the branch `claude/webxr-tetris-prototype-ak0cD` to `main`

2. **Enable GitHub Pages:**
   - Go to repository Settings
   - Scroll down to "Pages" section (in the left sidebar)
   - Under "Source", select `main` branch
   - Click "Save"

3. **Access your game:**
   - VR Headset: `https://harshavardhanr.github.io/Tetriswithcomms/index.html`
   - Phone: `https://harshavardhanr.github.io/Tetriswithcomms/phone.html`

### Option 2: Deploy from This Branch Directly

1. **Enable GitHub Pages:**
   - Go to: https://github.com/harshavardhanr/Tetriswithcomms/settings/pages
   - Under "Source", select branch: `claude/webxr-tetris-prototype-ak0cD`
   - Click "Save"

2. **Access your game:**
   - Same URLs as above
   - Wait 1-2 minutes for deployment

## Once It's Live

### On Your VR Headset:
1. Open browser
2. Go to: `https://harshavardhanr.github.io/Tetriswithcomms/index.html`
3. Click "Start AR Session"
4. Note the Peer ID (something like "vr-abc123xyz")

### On Your Phone:
1. Open browser
2. Go to: `https://harshavardhanr.github.io/Tetriswithcomms/phone.html`
3. Enter the Peer ID from your headset
4. Click "Connect"
5. Play!

## Benefits of GitHub Pages

✅ HTTPS by default (required for WebXR)
✅ No server setup needed
✅ Access from anywhere in the world
✅ Free hosting
✅ Automatic updates when you push changes

## Check If It's Already Enabled

Visit: https://github.com/harshavardhanr/Tetriswithcomms/settings/pages

If you see a green box saying "Your site is live at...", then it's already working!
